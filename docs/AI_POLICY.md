# Intelligence without privacy compromise
Core Clorix does not need an AI API key. The mandatory follow-up queue, pipeline insights and weighted forecast are deterministic and transparently labeled; calculations run locally/server-side on authorized CRM data. Never call them AI.

Optional isolated AI lab only after core passes: use Gemini official SDK and an immutable fictional example dataset bundled on server; accept only enumerated sample IDs/actions (e.g. suggested follow-up strategy for fictional case). No user prompts, real business records, notes, contact identifiers, metadata or user-entered fields sent to unpaid provider. Validate request and response with schema, no autonomous actions, no provider tools or outbound messages. UI says fictional sample and external provider; output drafts only. Store no provider raw payload in logs. Explicit request consent; eligible adult invited tester only, verified region/professional use and provider terms; do not offer unpaid AI to EEA, Switzerland or UK users or unknown eligibility. Public sandbox AI disabled. Provider failures show clear status, no canned substitute labeled AI. DB atomic quotas, timeout within Vercel limit, bounded concurrency and no retry storm.

Default EXTERNAL_AI_ENABLED=false. If policy/eligibility/key/model unavailable, do not expose module and document optional feature deferred. Do not activate paid billing. A future paid/private-data compliant provider integration requires separate consent, review and architecture work. Official Gemini terms effective March 23, 2026 checked during kit preparation; verify latest at deployment. See SOURCES.md.
