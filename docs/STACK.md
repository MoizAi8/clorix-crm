# Proposed stack and compatibility
- Next.js App Router + React + TypeScript strict, supported stable release compatible with Vercel and auth; Node LTS verified against CI/host, lockfile pinned. npm or pnpm (one, record decision). No speculative upgrade.
- Tailwind CSS + Radix/shadcn primitives, Lucide, Manrope/Inter, GSAP/Motion as needed. dnd-kit (or compatible maintained accessible DnD); explicit keyboard move menu mandatory. Recharts or small accessible SVG charts with data table fallback. TanStack Table/Query only if beneficial; server components + route handlers otherwise.
- Modular Next.js Node backend, Zod validation, Drizzle ORM + node-postgres compatible with Neon transaction pooling; SQL migrations with direct role. PostgreSQL 18 preferred if offered and compatible; otherwise supported version. Local test Postgres or isolated branch. Exact integer minor units for money. pg_trgm optional only if supported; indexed ILIKE/prefix/FTS as appropriate. No separate FastAPI/Redis/Celery requirement.
- Better Auth (stable compatible version) or equivalent maintained session auth library, database sessions, supported anonymous/guest integration if available; use library APIs, not improvised cookies. Document selected adapter, migration and session revocation behavior. If anonymous plugin unavailable, implement a supported secure server provisioning flow via library or switch compatible provider; no bypass. Auth password hash via maintained library; secure cookies and CSRF/origin checks.
- CSV parser with explicit size/row limits (e.g. Papa Parse server-side); no spreadsheet dependency required. Vitest, real PostgreSQL integration suite, Playwright, axe-core, lint/typecheck, CI.
- Optional Gemini via official SDK only in synthetic lab, no default external AI. No paid services. Database-backed rate limits; no process-local rate limits as sole defense on serverless.
- Vercel Hobby personal non-commercial evaluation, Neon Free, GitHub personal repo; verify quotas and eligibility. No background daemon dependency; opportunistic bounded cleanup + documented owner CLI. Avoid runtime migrations and unnecessary direct DB credentials in Vercel.

Validate chosen versions and actual driver behavior (pool transaction semantics, auth adapter, serverless time limits). Record exact versions, rationale and setup in README. Do not ship abandoned/vulnerable dependencies if fix available. Official docs links in SOURCES.md.
