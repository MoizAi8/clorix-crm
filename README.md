# Clorix
**From lead to loyalty.**

A planned full-stack CRM for tracking leads, contacts, companies, deals, tasks and customer relationships, with a real sales pipeline and database-backed reporting.

This repository begins as a pre-development kit. Start at [START_HERE.md](START_HERE.md). The approved theme is Midnight Growth Hybrid: dark sidebar, light workspace, selective lime/forest/mint accents. The live evaluation target is a real isolated synthetic sandbox. No enterprise or production client-use claim.
